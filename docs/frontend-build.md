# Building the Front End

This repository provides a small front-end that can be built with [Webpack](https://webpack.js.org/).

## Prerequisites
- Node.js >= 18
- npm (comes with Node.js)

## Setup
Install the front-end dependencies once:
```bash
npm install
```

## Development server
Run the development server with hot reloading:
```bash
npm start
```

## Production build
Create an optimized build using Webpack:
```bash
npm run build
```
The resulting files are placed in the `dist/` directory.

For more details on our UI layout, see the [Figma design](https://www.figma.com/file/example/Birdseye-Design).
